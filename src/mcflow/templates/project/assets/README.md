# assets

Drop files here that you want used in your plugin, resource pack or UI designs. You don't need to organise them. Claude looks here whenever a task needs art, sound or branding.

| What you drop | Used for | Good formats |
|---|---|---|
| Logos and icons | Item textures, GUI headers, font glyphs, mockups | PNG with transparency |
| Images and textures | Item and block textures, GUI backgrounds | PNG. Minecraft textures are usually 16×16 or a power of two. |
| Sounds | Custom sound events | OGG Vorbis (the only audio format Minecraft plays) |
| Models | Custom item and block models | Blockbench `.bbmodel`, or Minecraft JSON models |
| Video and GIFs | References for animations | Anything. Used as a reference, never shipped. |
| Sketches and screenshots | Layout ideas for GUIs and HUDs | Anything. These can also go in `layouts/`. |

Notes:

- Claude converts files into Minecraft's formats when it needs to. It never edits the originals here.
- If a file has a licence (for example a purchased asset pack), put the licence file next to it.
